# مراکز مراقبت سالمندان دانمارک

**نقشه‌ای از ۹۰۷ مرکز مراقبت سالمندان (plejecenter) در سراسر دانمارک — برای کسانی که دنبال کار در این مراکز هستند.**

### 👉 [plejefinder.online](https://plejefinder.online)

نیازی به نصب هیچ برنامه‌ای نیست. وب‌گاه را در گوشی یا رایانه باز کنید.

## چه چیزی پیدا می‌کنید

هر مرکز روی نقشه یک نقطه است. روی آن بزنید تا کارت آن باز شود:

| | |
|---|---|
| **نشانی** | با یک زدن در نقشهٔ گوگل یا نقشهٔ اپل باز می‌شود، یا رونوشت می‌گیرید |
| **تلفن** | برای ۸۹۷ مرکز از ۹۰۷ مرکز |
| **ایمیل** | برای ۷۶۹ مرکز |
| **وب‌سایت رسمی** | برای ۸۳۵ مرکز |
| **شغل** | جست‌وجوی گوگل برای آگهی‌های استخدام همان مرکز |
| **نوع اداره** | شهرداری، خودگردان، یا خصوصی |

</div>

<div dir="rtl">

## چطور مرکز مورد نظرتان را پیدا کنید

- **جست‌وجو** — نام مرکز، خیابان، کد پستی یا شهر
- **بخش کشور** — زلاند (Sjælland)، فیون (Fyn) یا یولاند (Jylland)
- **شهرداری** — از میان ۹۸ شهرداری دانمارک
- **نوع اداره** — شهرداری، خودگردان، خصوصی
- **موقعیت من** — فاصلهٔ هر مرکز تا شما به کیلومتر نشان داده می‌شود

</div>

<div dir="rtl">

## اگر حساب کاربری بسازید

ساختن حساب رایگان است و فقط به یک ایمیل و گذرواژه نیاز دارد.

- **ذخیرهٔ مکان‌ها** — مراکزی را که به آن‌ها علاقه دارید نشان بگذارید تا همه در یک جا باشند
- **یادداشت شخصی** — برای هر مرکز بنویسید کِی درخواست دادید، با چه کسی حرف زدید و چه گفتند؛ می‌توانید تاریخ بازدید هم ثبت کنید. **یادداشت‌های شما خصوصی‌اند و کسی جز خودتان آن‌ها را نمی‌بیند.**
- **امتیاز و نظر** — تجربه‌تان را با دیگران در میان بگذارید. نظرها پیش از نمایش خوانده می‌شوند.

هر وقت بخواهید می‌توانید حسابتان را حذف کنید؛ با آن، همهٔ مکان‌های ذخیره‌شده و یادداشت‌هایتان هم پاک می‌شوند.

## یک نکتهٔ مهم

داده‌ها از سامانهٔ رسمی دولت دانمارک گرفته شده‌اند، اما این سامانه فقط به‌اندازه‌ای به‌روز است که خود مراکز آن را به‌روز نگه دارند.

**برای آگاهی از جای خالی، فهرست انتظار یا استخدام، مستقیم به خود مرکز زنگ بزنید.** به نقشه اکتفا نکنید.
